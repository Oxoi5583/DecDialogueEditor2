# DecDialogueEditor2

## A Project for Better Game Dialogue Writing Experience

This is a C++ project for developing a GUI application which is for creating a dialogue data within GUI.
So that users (mainly me) could write dialogue logic with a WYSIWYG (What You See Is What You Get) interface.
And lastly, export dialogue data into different formats.
